# gallery

A demo for trying every naui widget, grouped by kind. The screens are split
into basics, input, lists, tables, navigation, layout, drawing, files, media,
dialogs, and async. The result of each action appears as a toast at the bottom
of the window.

```sh
cargo run -p gallery
```

Every control on screen is a real OS (or browser) widget: `NSButton` /
`NSTextField` on macOS, `<button>` / `<input>` on the Web.

## Running on the Web

`web/build.sh` builds for wasm and places the output in `web/pkg/`. You need the
wasm target and `wasm-bindgen-cli` at the same version as in `Cargo.lock` (if
anything is missing, the script tells you which commands to run).

```sh
cd examples/gallery/web
./build.sh
python3 -m http.server 8080
```

Then open <http://localhost:8080/>. The shared entry point for native and the
Web is generated by `naui::entry!`.
